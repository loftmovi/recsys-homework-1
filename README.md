## Запуск локально

Использовался Python 3.12. Запускать из корня распакованного проекта.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install -r requirements.txt
jupyter notebook experiments.ipynb
```

Выполнить ячейки сверху вниз. Данные автоматически скачиваются в `data/musical_instruments/`. Интернет нужен для первичной загрузки; скачанные файлы кешируются. Данные не включены в репозиторий и исключены через `.gitignore`.

## Данные и оценка

Исходных отзывов — 231 392. После удаления повторных пар пользователь–товар остаётся 219 156 взаимодействий. Сохраняем первый отзыв по времени.

Подвыборка формируется по популярности только в train: минимальный префикс товаров с не менее 110 000 обучающих взаимодействий и не менее 1 000 товаров. Итоговая подвыборка — 133 467 взаимодействий и 1 816 товаров; train содержит 24 270 пользователей.

Train: до 27.02.2017; validation: с 27.02.2017 до 01.10.2017; test: с 01.10.2017. В оценке только тёплые пользователи с хотя бы одним релевантным товаром. Положительный товар — оценка не ниже 4. Кандидаты — полный выбранный train-каталог без известных пользователю train-товаров. Обучение и история остаются только train; validation не добавляется при финальной оценке.

Основная метрика выбора — NDCG@10, дополнительная — Recall@10. Для каждого метода проверены две конфигурации. Для FM есть контроль без метаданных. Настройки зафиксированы до test.

## Результаты test

| Модель | NDCG@10 | Recall@10 |
|---|---:|---:|
| iALS | 0.024708 | 0.041601 |
| Custom iALS | 0.023412 | 0.038647 |
| EASE | 0.023132 | 0.040982 |
| FM | 0.022886 | 0.038073 |
| ItemCF | 0.021078 | 0.037869 |

Число оцениваемых пользователей test — 2 918. Собственный таргет `(rating - 1) / 4` не улучшил базовый iALS. Бренд и категории не дали устойчивого улучшения FM. Все подробности и ограничения приведены в ноутбуке.

Ограничения: популярная часть каталога, исключение холодных пользователей, один seed и временной split, небольшой поиск параметров. Метаданные представлены статическим снимком; бренд и категории считаются постоянными, но их точная историческая доступность не подтверждена источником.
